# 9과. 약어

약어는 자주 쓰는 말을 한 획에 치는 방법입니다. 처음부터 다 외우려 하지 말고, 음절로 치다가 자주 쓰는 것부터 하나씩 바꿔 가세요. 모르는 약어는 획 찾기([10과](10-명령과-내-사전.md))로 찾을 수 있습니다.

## 한 키 약어

초성 키 하나만 누르면 아래 말이 나옵니다. "리"는 앞말에 붙습니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱ` | `e` | 그것 |
| `ㄴ` | `t` | 누구 |
| `ㄷ` | `a` | 다시 |
| `ㄹ` | `g` | 리 |
| `ㅁ` | `w` | 말 |
| `ㅂ` | `f` | 밝 |
| `ㅅ` | `d` | 생각 |
| `ㅇ` | `s` | 이것 |
| `ㅈ` | `r` | 저것 |
| `ㅎ` | `q` | 해 |
| `-ㅂ` | `h` | 법 |

## 이것·그것·저것·우리

초성 키에 받침 쪽 조사 키(ㄴ 은, ㄹ 을, ㄷ 도)를 더합니다. "그것이"만 `ㄱ-ㅇ`이고, "이것이"·"저것이"는 `*`를 씁니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅇ-ㄴ` | `s j` | 이것은 |
| `ㅇ-ㄹ` | `s i` | 이것을 |
| `ㅇ-ㄷ` | `s p` | 이것도 |
| `ㅇ*` | `s b` | 이것이 |
| `ㄱ-ㄴ` | `e j` | 그것은 |
| `ㄱ-ㄹ` | `e i` | 그것을 |
| `ㄱ-ㄷ` | `e p` | 그것도 |
| `ㄱ-ㅇ` | `e u` | 그것이 |
| `ㅈ-ㄴ` | `r j` | 저것은 |
| `ㅈ-ㄹ` | `r i` | 저것을 |
| `ㅈ-ㄷ` | `r p` | 저것도 |
| `ㅈ*` | `r b` | 저것이 |
| `ㅇㅜ` | `s v` | 우리 |
| `ㅇㅜㄴ` | `s v j` | 우리는 |
| `ㅇㅜㄹ` | `s v i` | 우리를 |
| `ㅇㅜㄷ` | `s v p` | 우리도 |
| `ㅇㅜㄱㄷ` | `s v o p` | 우리가 |
| `ㄱㅅ` | `e d` | 것 |
| `ㄱㅅㅣㄷ` | `e d m p` | 것이다 |

## 하다

받침 ㅎ(`y`)이 "하"이고, 함께 누르는 받침이 뒷말입니다(ㄱ 고, ㅁ 며, ㅈ 지, ㄷ 다, ㅅ 서…).

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `-ㅎㄱ` | `y o` | 하고 |
| `-ㅎㅁ` | `y ;` | 하며 |
| `-ㅎㅇ` | `y u` | 하여 |
| `-ㅎㅈ` | `y l` | 하지 |
| `-ㅎㄷ` | `y p` | 하다 |
| `ㅎ-ㄴ` | `q j` | 하는 |
| `-ㅎㅅ` | `y k` | 해서 |
| `ㅎ-ㄷ` | `q p` | 해도 |
| `ㅎㄱ*` | `q e b` | 하기 |
| `-ㅎㄴ` | `y j` | 한 |
| `-ㅎㄹ` | `y i` | 할 |

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅗㅇ/ㅂㅜ/-ㅎㄱ` | `e x u` → `f v` → `y o` | 공부하고 |
| `ㄱㅗㅇ/ㅂㅜ/ㅎ-ㄴ` | `e x u` → `f v` → `q j` | 공부하는 |

## 접속사

`ㄱㄹ`(`e g`)이 "그"이고, 받침 쪽 키로 뒷말을 고릅니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㄹ-ㄱ` | `e g o` | 그리고 |
| `ㄱㄹ-ㄴ` | `e g j` | 그러나 |
| `ㄱㄹ-ㅅ` | `e g k` | 그래서 |
| `ㄱㄹ-ㄷ` | `e g p` | 그래도 |
| `ㄱㄹㅓㄷㄴ` | `e g n p j` | 그런데 |
| `ㄱㄹㅏㅣ` | `e g c m` | 그래 |
| `ㄱㄹㅣ` | `e g m` | 그리 |
| `ㄷㅇㄹ-ㅅ` | `a s g k` | 따라서 |
| `ㄱㅏ/ㄷㅇㄹㅏ` | `e c` → `a s g c` | 가에 따라 |
| `ㄱㅏ/ㄷㅇㄹㅏㅅ` | `e c` → `a s g c k` | 가에 따라서 |

## 양손 약어 (모음 없이)

첫 음절의 초성을 왼손, 둘째 음절의 초성을 오른손 받침 자리로 누르는 두 음절 단어 약어입니다. 대부분 받침이 없는 두 글자 명사입니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱ-ㅎ` | `e y` | 기회 |
| `ㅅ-ㅎ` | `d y` | 사회 |
| `ㅈ-ㅎ` | `r y` | 조화 |
| `ㅅ-ㅂ` | `d h` | 소비 |
| `ㅇ-ㅈ` | `s l` | 이제 |
| `ㅅ-ㄷ` | `d p` | 시대 |
| `ㅇ-ㄱ` | `s o` | 외교 |
| `ㅇ-ㅎ` | `s y` | 의회 |
| `ㅇ-ㅁ` | `s ;` | 이미 |
| `ㄷ-ㅂ` | `a h` | 대비 |
| `ㅇ-ㅅ` | `s k` | 의사 |
| `ㅁ-ㅇ` | `w u` | 매우 |
| `ㅅ-ㄱ` | `d o` | 사고 |
| `ㅈ-ㅇ` | `r u` | 주의 |
| `ㅅ-ㅁ` | `d ;` | 사무 |
| `ㅁ-ㄷ` | `w p` | 모두 |

가운데에 `*`(`b`)를 넣는 약어도 있습니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅁ*ㄹ` | `w b i` | 미래 |
| `ㅈ*ㅇ` | `r b u` | 자유 |
| `ㅅ*ㄱ` | `d b o` | 세계 |
| `ㅂ*ㅁ` | `f b ;` | 부모 |
| `ㅈ*ㅈ` | `r b l` | 자주 |
| `ㅇ*ㅈ` | `s b l` | 의지 |
| `ㄴ*ㅅ` | `t b k` | 뉴스 |
| `ㄹ*ㄷ` | `g b p` | 리더 |
| `ㄷ*ㅈ` | `a b l` | 대조 |
| `ㅇ*ㅁ` | `s b ;` | 의미 |
| `ㅇ*ㄱ` | `s b o` | 요구 |
| `ㄷ*ㅎ` | `a b y` | 대화 |
| `ㅎ*ㅇ` | `q b u` | 회의 |
| `ㅇ*ㅅ` | `s b k` | 이사 |
| `ㅅ*ㄴ` | `d b j` | 소녀 |

| 획 | 누를 키 | 결과 |

| `ㅎㄴㅏ` | `q t c` | 하나 |

## 약어 공부 요령

- 다 외우려 하지 마세요. 약어를 몰라도 음절로 치면 됩니다.
- 먼저 익힐 것: 것(`ㄱㅅ`), 있·없·했, ~습니다 계열([8과](08-어미.md)), 그리고·그래서, 하고·하는.
- 자주 쓰는데 약어가 없는 말은 내 사전에 직접 추가하세요([10과](10-명령과-내-사전.md)).
