# 8과. 어미 — 끝말을 한 획에

## 원리

받침 자리에서 실제 받침으로 쓰이지 않는 조합에 자주 쓰는 끝말이 배정돼 있습니다. 초성·모음과 함께 누르면 "음절 + 끝말"이 한 획에 나옵니다. 예를 들어 받침 자리의 ㅂ+ㄴ(`h j`)은 "ㅂ니다"라서, "가"와 함께 누르면 "갑니다"가 됩니다.

## 문장을 끝내는 말

| 끝말 | 획 | 누를 키 | 예 |
| --- | --- | --- | --- |
| ~ㄴ다 | `ㄱㅏㄷㄴ` | `e c p j` | 간다 |
| ~ㅂ니다 | `ㄱㅏㅂㄴ` | `e c h j` | 갑니다 |
| ~ㅂ니까 | `ㄱㅏㅂㄴㅅ` | `e c h j k` | 갑니까 |
| ~ㅂ시다 | `ㄱㅏㄷㅂㅅ` | `e c p h k` | 갑시다 |
| ~ㅆ다 | `ㄱㅏㄷㅅ` | `e c p k` | 갔다 |
| ~ㅆ습니다 | `ㄱㅏㅂㄴㅅㅈ` | `e c h j k l` | 갔습니다 |
| ~ㅆ습니까 | `ㄱㅏㅂㄴㅅㅁ` | `e c h j k ;` | 갔습니까 |

**주의**: ~ㅆ다, ~ㅆ습니다는 앞 음절에 받침 ㅆ을 붙이는 것입니다. 그래서 모음을 과거형 모양대로 쳐야 합니다. "보다"의 과거는 "봐"에 ㅆ을 붙이므로 ㅘ로 칩니다. "하다"의 과거 "했다"는 이 방법으로 칠 수 없어서 아래의 음절 약어 "했"을 씁니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅂㅗㅏㄷㅅ` | `f x c p k` | 봤다 (맞음) |
| `ㅂㅗㄷㅅ` | `f x p k` | 봈다 (틀림) |
| `ㅎㅏㄷㅅ` | `q c p k` | 핬다 (틀림) |
| `ㅎㅁ/ㄷㅏ` | `q w` → `a c` | 했다 (약어, 맞음) |

## 이어 주는 말 (받침 없는 음절 뒤)

| 끝말 | 획 | 누를 키 | 예 |
| --- | --- | --- | --- |
| ~다 | `ㄱㅏㄷㅈ` | `e c p l` | 가다 |
| ~고 | `ㄱㅏㅇㄹㄱㄷ` | `e c u i o p` | 가고 |
| ~지 | `ㄱㅏㄱㅈ` | `e c o l` | 가지 |
| ~지만 | `ㄱㅏㅈㅁ` | `e c l ;` | 가지만 |
| ~게 | `ㄱㅏㅅㅈ` | `e c k l` | 가게 |
| ~면 | `ㄱㅏㄴㅁ` | `e c j ;` | 가면 |
| ~면서 | `ㄱㅏㄴㅅㅁ` | `e c j k ;` | 가면서 |
| ~도 | `ㄱㅏㄷㅁ` | `e c p ;` | 가도 |
| ~니까 | `ㄱㅏㄴㅅㅈ` | `e c j k l` | 가니까 |
| ~도록 | `ㄱㅏㄹㄱㄷ` | `e c i o p` | 가도록 |
| ~라 | `ㄱㅏㅎㅇㄹ` | `e c y u i` | 가라 |
| ~는 | `ㅂㅗㄴㅅㅈㅁ` | `f x j k l ;` | 보는 |

## ㄴ·ㄹ·ㅂ으로 시작하는 말

| 끝말 | 획 | 누를 키 | 예 |
| --- | --- | --- | --- |
| ~ㄴ가 | `ㅣㄱㄴ` | `m o j` | 인가 |
| ~ㄴ지 | `ㅣㄱㄴㅈ` | `m o j l` | 인지 |
| ~ㄴ다고 | `ㄱㅏㄱㄷㄴ` | `e c o p j` | 간다고 |
| ~ㄹ 때 | `ㄱㅏㄹㄷ` | `e c i p` | 갈 때 |
| ~ㄹ지 | `ㄱㅏㄹㅈ` | `e c i l` | 갈지 |
| ~ㄹ까 | `ㄱㅏㄹㄱㅁ` | `e c i o ;` | 갈까 |
| ~ㅂ다 | `ㅎㅈㅜㄷㅂ` | `q r v p h` | 춥다 |
| ~ㅂ게 | `ㅅㅜㅣㄱㅂ` | `d v m o h` | 쉽게 |
| ~ㅂ고 | `ㅎㅈㅜㅂㅅㅈ` | `q r v h k l` | 춥고 |
| ~ㅂ지 | `ㅎㅈㅜㅂㅈ` | `q r v h l` | 춥지 |
| ~ㅂ지만 | `ㅎㅈㅜㅂㅈㅁ` | `q r v h l ;` | 춥지만 |
| ~운 | `ㅓ/ㄹ*ㅓㅇㄴ` | `n` → `g b n u j` | 어려운 |
| ~울 | `ㅓ/ㄹ*ㅓㅇㄹ` | `n` → `g b n u i` | 어려울 |
| ~움 | `ㅓ/ㄹ*ㅓㅇㅁ` | `n` → `g b n u ;` | 어려움 |

## 자주 쓰는 음절 약어

초성 쪽 키만으로 자주 쓰는 음절을 칩니다. 뒤에 오는 말과 붙습니다.

| 음절 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| 했 | `ㅎㅁ` | `q w` | 했 |
| 있 | `ㅇㅅ` | `s d` | 있 |
| 없 | `ㅇㅂ` | `s f` | 없 |
| 았 | `ㅇㅏ` | `s c` | 았 |
| 었 | `ㅇㅓ` | `s n` | 었 |
| 였 | `ㅇ*ㅓ` | `s b n` | 였 |
| 겠 | `ㄱㅅ*` | `e d b` | 겠 |
| 않 | `ㄴㅇ-ㅎ` | `t s y` | 않 |
| 많 | `ㅁ-ㅎ` | `w y` | 많 |

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅎㅁ/ㄷㅏ` | `q w` → `a c` | 했다 |
| `ㅁㅓㄱ/ㅇㅓ/ㄷㅏ` | `w n o` → `s n` → `a c` | 먹었다 |
| `ㅇㅅ/ㄷㅏ` | `s d` → `a c` | 있다 |
| `ㅇㅂ/ㄷㅏ` | `s f` → `a c` | 없다 |

## 문장 끝 약어 (마침표까지)

음절 약어에 `-ㅂㄴ`(`h j`)을 더하면 "~습니다.", `-ㅂㄴㅅ`(`h j k`)을 더하면 "~습니까?"가 됩니다. 문장부호까지 함께 나옵니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅎㅁ-ㅂㄴ` | `q w h j` | 했습니다. |
| `ㅎㅁ-ㅂㄴㅅ` | `q w h j k` | 했습니까? |
| `ㅇㅅ-ㅂㄴ` | `s d h j` | 있습니다. |
| `ㅇㅅ-ㅂㄴㅅ` | `s d h j k` | 있습니까? |
| `ㅇㅂ-ㅂㄴ` | `s f h j` | 없습니다. |
| `ㅇㅂ-ㅂㄴㅅ` | `s f h j k` | 없습니까? |
| `ㅇㅏㅂㄴ` | `s c h j` | 았습니다. |
| `ㅇㅓㅂㄴ` | `s n h j` | 었습니다. |
| `ㅇ*ㅓㅂㄴ` | `s b n h j` | 였습니다. |
| `ㄱㅅ*ㅂㄴ` | `e d b h j` | 겠습니다. |
| `ㄴㅇ-ㅂㄴ` | `t s h j` | 않습니다. |
| `ㅁ-ㅂㄴ` | `w h j` | 많습니다. |

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅁㅓㄱ/ㅇㅓㅂㄴ` | `w n o` → `s n h j` | 먹었습니다. |
| `ㄱㅏ/ㄱㅅ*ㅂㄴ` | `e c` → `e d b h j` | 가겠습니다. |
| `ㄱㅗㅇ/ㅂㅜ/ㅎㅁ-ㅂㄴ` | `e x u` → `f v` → `q w h j` | 공부했습니다. |
