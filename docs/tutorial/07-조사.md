# 7과. 조사

## 조사는 앞말에 붙고, 뒤는 자동으로 띄어진다

조사 획은 앞 단어에 자동으로 붙고, 조사 뒤에는 자동으로 띄어쓰기가 들어갑니다. 그래서 조사 뒤에는 `*`를 치지 않습니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅅㅏ/ㄱㅗㅏ/-ㄴ/ㅁㅏㅅ/ㅣㅇㅅ/ㄷㅏ` | `d c` → `e x c` → `j` → `w c k` → `m u k` → `a c` | 사과는 맛있다 |

## 왜 이런 획일까

- **초성 ㅇ 키 + 모음 = 조사**: 초성 ㅇ은 음절을 칠 때 누르지 않으므로, `ㅇㅣ`(이), `ㅇㅓㅣ`(에), `ㅇㅗㅏ`(와/과)처럼 비어 있는 조합을 조사에 씁니다.
- **받침 키만 = 조사**: 초성과 모음 없이 받침 키만 누르는 조합도 음절이 될 수 없으므로 조사에 씁니다. `-ㄴ`(는), `-ㄹ`(을/를), `-ㅇ`(의), `-ㄷ`(도)처럼요.

## 가장 많이 쓰는 조사

은/는, 이/가는 앞말에 받침이 있는지 보고 **직접 골라** 칩니다. 을/를, 와/과는 Plover가 **자동으로 골라** 줍니다.

| 조사 | 획 | 누를 키 | 예 |
| --- | --- | --- | --- |
| 은 | `ㅎㅈㅏㅣㄱ/-ㅇㄴ` | `q r c m o` → `u j` | 책은 |
| 는 | `ㄴㅏ/-ㄴ` | `t c` → `j` | 나는 |
| 이 | `ㅎㅈㅏㅣㄱ/ㅇㅣ` | `q r c m o` → `s m` | 책이 |
| 가 | `ㅅㅏ/ㄱㅗㅏ/-ㄱㄷ` | `d c` → `e x c` → `o p` | 사과가 |
| 을/를 (자동) | `ㅎㅈㅏㅣㄱ/-ㄹ` | `q r c m o` → `i` | 책을 |
| 을/를 (자동) | `ㅅㅏ/ㄱㅗㅏ/-ㄹ` | `d c` → `e x c` → `i` | 사과를 |
| 와/과 (자동) | `ㅎㅈㅏㅣㄱ/ㅇㅗㅏ` | `q r c m o` → `s x c` | 책과 |
| 와/과 (자동) | `ㅅㅏ/ㄱㅗㅏ/ㅇㅗㅏ` | `d c` → `e x c` → `s x c` | 사과와 |
| 의 | `ㄴㅏ/-ㅇ` | `t c` → `u` | 나의 |
| 에 | `ㅈㅣㅂ/ㅇㅓㅣ` | `r m h` → `s n m` | 집에 |
| 에서 | `ㅎㅏㄱ/ㄱㅗ*/ㅇㅓㅣㅅ` | `q c o` → `e x b` → `s n m k` | 학교에서 |
| 에게 | `ㄴㅏ/ㅇㅓㅣㄱ` | `t c` → `s n m o` | 나에게 |
| 도 | `ㄴㅏ/-ㄷ` | `t c` → `p` | 나도 |
| 부터 | `ㅗ/ㄴㅏㅓㄹ/-ㅎㄷㅂ` | `x` → `t c n i` → `y p h` | 오늘부터 |
| 이다 | `ㅎㅏㄱ/ㅅㅏㅣㅇ/ㅇㅣㄷ` | `q c o` → `d c m u` → `s m p` | 학생이다 |

"이다"는 뒤에 오는 말과 붙습니다. 그래서 "학생이다" 다음에 다른 단어를 칠 때는 `*`로 띄워야 합니다.

## 조사 획과 음절 획

"을"은 음절로도 칠 수 있습니다(`ㅏㅓㄹ`, ㅡ+받침 ㄹ). 둘 다 한 획이지만, 음절 "을"은 뒷말과 붙어 버리고 조사 획은 뒤를 띄워 줍니다. 그래서 조사로 쓸 때는 조사 획이 띄어쓰기 한 획을 아껴 줍니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅎㅈㅏㅣㄱ/ㅏㅓㄹ/ㅣㄹㄱ/ㄷㅏ` | `q r c m o` → `c n i` → `m i o` → `a c` | 책을읽다 (음절 "을": 붙어 버림) |
| `ㅎㅈㅏㅣㄱ/-ㄹ/ㅣㄹㄱ/ㄷㅏ` | `q r c m o` → `i` → `m i o` → `a c` | 책을 읽다 (조사 획) |

반대로 "을지로", "과일"처럼 **을·과로 시작하는 단어**는 음절로 칩니다. 이것도 한 획이라 조사 획이 더 빠르지 않고, 조사 획은 뒤를 띄우기 때문에 오히려 단어가 갈라집니다. 조사 획을 앞말 없이 맨 처음에 치면 받침 있을 때 형태(을·과)가 나옵니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅏㅓㄹ/ㅈㅣ/ㄹㅗ` | `c n i` → `r m` → `g x` | 을지로 (음절, 맞음) |
| `-ㄹ/ㅈㅣ/ㄹㅗ` | `i` → `r m` → `g x` | 을 지로 (조사 획, 틀림) |
| `ㄱㅗㅏ/ㅣㄹ` | `e x c` → `m i` | 과일 |
