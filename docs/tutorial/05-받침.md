# 5과. 받침

받침은 오른손으로 초성·모음과 함께 누릅니다. 한 음절이 여전히 한 획입니다.

| 받침 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㄱ | `ㄱㅏㄱ` | `e c o` | 각 |
| ㄴ | `ㄱㅏㄴ` | `e c j` | 간 |
| ㄷ | `ㄱㅏㄷ` | `e c p` | 갇 |
| ㄹ | `ㄱㅏㄹ` | `e c i` | 갈 |

| ㅅ | `ㄱㅏㅅ` | `e c k` | 갓 |

## 쌍받침·거센 받침: 초성과 같은 방법

초성처럼 ㅇ(`u`)을 더하면 ㄲ·ㅆ, ㅎ(`y`)을 더하면 ㅊ·ㅋ·ㅌ·ㅍ입니다. 오른쪽의 ㅇ과 ㅎ 자리를 쓴다는 점만 다릅니다.

| 받침 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㄲ | `ㅂㅏㅇㄱ` | `f c u o` | 밖 |
| ㅆ | `ㅣㅇㅅ` | `m u k` | 있 |
| ㅊ | `ㄱㅇㅗㅎㅈ` | `e s x y l` | 꽃 |
| ㅋ | `ㅂㅜ/ㅓㅎㄱ` | `f v` → `n y o` | 부엌 |
| ㅌ | `ㅂㅏㅎㄷ` | `f c y p` | 밭 |
| ㅍ | `ㅏㅎㅂ` | `c y h` | 앞 |

## 다시 한번: 초성 ㅇ은 누르지 않는다

받침이 붙어도 마찬가지입니다. "읽"을 칠 때 초성 ㅇ(`s`)을 같이 누르면 글자로 바뀌지 않고 속기 표기가 그대로 나옵니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅣㄹㄱ` | `m i o` | 읽 (맞음) |
| `ㅇㅣㄹㄱ` | `s m i o` | ㅇㅣㄹㄱ (변환 안 됨) |

## 받침 자리의 특별한 조합

받침으로 쓰이지 않는 조합(예: ㄷ+ㄴ)에는 자주 쓰는 끝말이 배정돼 있습니다. 예를 들어 `ㄱㅏㄷㄴ`은 "간다"입니다. [8과](08-어미.md)에서 배웁니다.
