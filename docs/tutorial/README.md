# 한글 속기 튜토리얼

Plover와 한글 속기 플러그인(`plover_korean`, 시스템 이름 **Korean Modern C**)으로 **일반 키보드에서** 한글 CAS 속기를 처음 배우는 사람을 위한 튜토리얼입니다.

플러그인에 들어 있는 원래 자료는 원작자가 CAS 이론서(『컴퓨터 속기 I』)를 공부하며 적은 짧은 영어 메모입니다. 이 튜토리얼은 그 메모를 실제 사전과 하나하나 대조해서, 이 저장소의 플러그인과 키 배치에 맞춰 다시 썼습니다. 표에 나오는 예제는 모두 Plover 엔진에 직접 넣어서 결과를 확인한 것입니다.

## 공부 방법

- **1~5과가 기본기입니다.** 한글은 음절만 칠 줄 알면 무엇이든 쓸 수 있습니다. 여기까지는 천천히, 키보드를 보지 않고 정확하게 연습하세요.
- **6과부터는 빨리 치기 위한 기술입니다.** 조사·어미·약어는 한꺼번에 외우지 말고, 자주 쓰는 것부터 하나씩 익히세요.
- 하루 15~20분씩 자주 하는 편이 한 번에 오래 하는 것보다 낫습니다.
- 속도보다 정확도가 먼저입니다. 틀리면 되돌리기(`h j`)로 지우고 다시 치세요.

## 표 읽는 법

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅅㅏ/ㄱㅗㅏ` | `d c` → `e x c` | 사과 |

- **획**: 속기 표기입니다. 읽는 법은 [2과](02-자판.md#속기-표기-읽는-법)에 있습니다. `/`는 획과 획의 구분입니다.
- **누를 키**: 한 칸 안의 키는 **동시에** 눌렀다 뗍니다. `→`는 다음 획입니다. 키는 왼손(초성), 엄지(모음), 오른손(받침) 순서로 적었습니다.
- **결과**: 화면에 나오는 글자입니다.

## 이 이론으로 할 수 있는 것과 없는 것

- 모든 한글 음절을 한 획에 하나씩 칠 수 있습니다.
- 사전에 든 약어·조사·어미는 약 280개입니다. 실제 속기사 사전(수만 개)보다 훨씬 작으니, 자주 쓰는 말은 [10과](10-명령과-내-사전.md)처럼 내 사전에 추가해 가면 됩니다.
- 알려진 제약:
  - 원래 이론에 있는 "ㄹ 수"(`-ㄹㅅ`)는 겹받침 ㄽ과 겹쳐서 빠져 있습니다.
  - 마침표·쉼표·물음표·느낌표 말고 다른 기호는 띄어쓰기가 어색하게 들어갈 수 있습니다.
  - 획 찾기로는 사전에 든 말만 찾을 수 있습니다. 음절 조합으로 만드는 글자는 찾을 수 없습니다.
