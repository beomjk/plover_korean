# 10과. 명령과 내 사전

## 한국어 모드 명령

모두 "플로"(`ㅎㅂㄹㅗ`, `q f g x`)로 시작하고, 받침 하나로 명령을 고릅니다. ㅇ은 영어, ㄷ은 단어, ㅅ은 사전으로 외우면 쉽습니다.

| 하는 일 | 획 | 누를 키 |
| --- | --- | --- |
| Plover 켜기·끄기 | `ㅎㅂㄹㅗ` | `q f g x` |
| 영어로 전환 | `ㅎㅂㄹㅗㅇ` | `q f g x u` |
| 단어 추가 창 열기 | `ㅎㅂㄹㅗㄷ` | `q f g x p` |
| 획 찾기 창 열기 | `ㅎㅂㄹㅗㅅ` | `q f g x k` |

## 영어 모드 명령

| 하는 일 | 영어 속기 표기 | 누를 키 |
| --- | --- | --- |
| 한국어로 전환 | `KPHRO*` | `s e r f v t` |
| Plover 켜기·끄기 | `PHROLG` | `e r f v o l` |

## 내 사전에 단어 추가하기

Plover가 켜져 있는 동안은 키보드를 Plover가 쓰고 있어서 Tab이나 Enter를 칠 수 없습니다. 칸을 옮기거나 저장할 때는 마우스를 쓰고, 글자는 속기로 쳐 넣습니다.

1. 한국어 모드에서 `q f g x p`를 치면 **Add Translation** 창이 열립니다.
2. **Strokes** 칸에서 쓰고 싶은 획을 칩니다. 여러 획이면 차례로 칩니다.
3. 마우스로 **Translation** 칸을 누르고, 나올 말을 속기로 음절 단위로 쳐 넣습니다.
4. **Dictionary**가 `ko_user.json`인지 확인하고 **OK**를 누릅니다.

내 사전(`ko_user.json`)은 플러그인 사전보다 우선합니다. 같은 획을 넣으면 내 것이 이깁니다. 파일은 `~/Library/Application Support/plover/ko_user.json`에 있습니다. 직접 편집할 때는 Plover를 끄고 하세요.

**띄어쓰기 규칙**: 그냥 "대한민국"처럼 넣으면 앞뒤가 띄어집니다. 뒤에 오는 말과 붙여야 하면 끝에 `{^}`를, 앞말에 붙여야 하면 앞에 `{^}`를 씁니다. 예: `공부{^}`, `{^}께서`.

## 획 찾기

`q f g x k`를 치면 **Lookup** 창이 열립니다. 찾을 말을 속기로 쳐 넣으면 그 말을 내는 획이 나옵니다.

약어·조사·어미처럼 **사전에 든 말만** 찾을 수 있습니다. "사과"처럼 음절을 조합해서 치는 말은 사전에 들어 있지 않아서 찾을 수 없습니다.

## Uni v4를 쓰게 되면

영어는 Uni v4(Gemini PR), 한국어는 키보드로 칠 계획이라면, 한국어에서 영어로 돌아갈 때 장치도 바꿔야 합니다. `ko_user.json`에 아래 항목을 넣으면 같은 획(`q f g x u`)이 장치까지 바꿉니다. 영어에서 한국어로 오는 `KPHRO*`는 이미 키보드로 바꾸게 되어 있어 그대로 두면 됩니다.

```json
{
"ㅎㅂㄹㅗㅇ": "{PLOVER:SET_CONFIG:'system_name':'English Stenotype','machine_type':'Gemini PR'}"
}
```
