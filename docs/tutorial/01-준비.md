# 1과. 준비

이 과에서는 Plover를 한국어 모드로 바꾸고, 속기의 기본 단위인 **획**을 익힙니다. Plover와 플러그인 설치는 [저장소 README](../../README.md#installation)를 보세요.

## 1. 입력 소스는 ABC로

Plover를 쓰는 동안에는 macOS 입력 소스를 **ABC**로 두세요. 2벌식이 켜져 있으면 Plover가 보내는 영문자·공백·문장부호가 한글 입력기를 거치면서 다른 글자로 바뀔 수 있습니다. 한글 속기는 Plover가 완성된 글자(예: "가")를 직접 보내므로 ABC 상태에서도 한글이 제대로 나옵니다.

## 2. Plover 켜고 끄기

Plover 창의 메뉴와 버튼은 영어로 나옵니다. Plover에는 한국어 화면이 없습니다.

- 창의 **Output** 항목에서 **Enabled**를 고르면 켜지고, **Disabled**를 고르면 꺼집니다.
- 켜져 있는 동안에는 키보드가 속기 장치가 되어 평소처럼 타이핑할 수 없습니다. 평소 타이핑을 할 때는 끄세요.

## 3. 한국어로 전환하기

Plover는 마지막으로 쓰던 모드로 켜지고, 처음에는 영어 모드입니다. 영어 모드에서 한국어로 넘어오는 획은 Plover 영어 사전에 없어서, 처음 한 번만 직접 넣어 줍니다.

### 처음 한 번만: 전환 획 넣기

1. Plover 창에서 **File → Open config folder**를 눌러 설정 폴더를 엽니다.
2. **File → Quit Plover**로 Plover를 끕니다. 사전 파일은 Plover가 꺼져 있을 때 고쳐야 합니다.
3. 설정 폴더의 `user.json`을 텍스트 편집기(TextEdit 등)로 열고, 내용을 아래로 바꿉니다. 처음 설치한 상태라면 파일에는 `{`와 `}`만 있습니다.

```json
{
"KPHRO*": "{PLOVER:SET_CONFIG:'system_name':'Korean Modern C','machine_type':'Keyboard'}"
}
```

TextEdit에서 직접 치면 따옴표가 둥근 따옴표로 바뀔 수 있으니, 위 내용을 복사해서 붙여 넣으세요. 이미 다른 항목이 있다면 `{` 다음 줄에 `"KPHRO*"` 줄만 넣고, 그 줄 끝에 쉼표(`,`)를 붙입니다.

4. 저장하고 Plover를 다시 켭니다.

### 전환하기

Output을 켠 상태에서 아래 획을 치면 한국어 모드로 바뀝니다.

| 하는 일 | 영어 속기 표기 | 누를 키 |
| --- | --- | --- |
| 한국어로 전환 | `KPHRO*` | `s e r f v t` |

`t` 대신 `g`, `y`, `h` 중 아무거나 눌러도 됩니다. 영어 속기의 `*` 키가 이 네 자리에 있기 때문입니다.

제대로 바뀌었는지는 `e c`를 동시에 눌러 보면 알 수 있습니다. "가"가 나오면 한국어 모드입니다.

한국어 모드에서 영어로 돌아가거나 Plover를 끄고 켤 때는 아래 획을 씁니다.

| 하는 일 | 획 | 누를 키 |
| --- | --- | --- |
| 영어로 전환 | `ㅎㅂㄹㅗㅇ` | `q f g x u` |
| Plover 켜기·끄기 | `ㅎㅂㄹㅗ` | `q f g x` |

켜기·끄기 획은 Plover가 꺼진 상태에서도 동작해서, 끈 뒤 다시 켤 때도 쓸 수 있습니다. 다만 꺼져 있을 때는 Plover가 키보드를 막지 않으므로, 누른 키의 글자(`qfgx` 같은)가 먼저 화면에 찍힌 뒤 켜집니다. 찍힌 글자는 지우면 됩니다.

## 4. 획이란

속기에서는 키를 하나씩 치지 않고, 여러 키를 **한꺼번에 눌렀다가 모두 뗍니다.** 키를 다 떼는 순간 눌렀던 키 전부가 한 번에 입력되는데, 이 한 번을 **획**이라고 합니다.

- 누르는 순서는 상관없습니다. 동시에 눌려 있던 키가 모두 한 획이 됩니다.
- 한글 속기에서는 **한 획이 보통 한 음절**입니다. "각"이라면 초성 ㄱ, 모음 ㅏ, 받침 ㄱ을 한꺼번에 누릅니다.
- 음절과 음절은 자동으로 붙습니다. 단어 사이는 띄어쓰기 획으로 띄웁니다.

해 보세요.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ` | `e c` | 가 |
| `ㄱㅏ/ㄴㅏ` | `e c` → `t c` | 가나 |
| `ㄱㅏㄱ` | `e c o` | 각 |
| `ㄱㅏ/*/ㄴㅏ` | `e c` → `b` → `t c` | 가 나 |

## 5. Paper Tape 켜 두기

Plover 창의 **Tools → Paper Tape**를 열면 방금 친 획이 속기 표기로 기록됩니다. 생각한 대로 나오지 않을 때 실제로 어떤 키가 눌렸는지 확인할 수 있어서, 연습할 때 켜 두면 좋습니다. 한글이 어긋나 보이면 고정폭 한글 글꼴(예: Nanum Gothic Coding)을 쓰면 낫습니다.

## 6. 처음부터 알아 둘 획

띄어쓰기와 되돌리기는 1과부터 계속 씁니다. 자세한 내용은 [6과](06-띄어쓰기와-고치기.md)에 있습니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ/*/ㄴㅏ` | `e c` → `b` → `t c` | 가 나 (띄어쓰기) |
| `ㄱㅏ/ㄴㅏ/-ㅂㄴ` | `e c` → `t c` → `h j` | 가 ("나"가 취소됨) |
