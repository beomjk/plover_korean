# 3과. 모음 — 엄지만으로

## 초성 ㅇ은 치지 않는다

"아"의 초성 ㅇ은 소리가 없습니다. 그래서 속기에서는 **초성 ㅇ을 아예 누르지 않습니다.** "아"는 모음 ㅏ만 누르면 됩니다.

이 규칙 덕분에 비어 있게 된 초성 ㅇ 키(`s`)는 된소리, 조사, 약어에 쓰입니다. 실수로 `s`를 같이 누르면 엉뚱한 글자가 나오니 주의하세요.

## 기본 모음 5개

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅏ | `ㅏ` | `c` | 아 |
| ㅓ | `ㅓ` | `n` | 어 |
| ㅗ | `ㅗ` | `x` | 오 |
| ㅜ | `ㅜ` | `v` | 우 |
| ㅣ | `ㅣ` | `m` | 이 |

## 나머지는 조합으로

아래 규칙으로 모음 21개를 모두 칩니다. 두 키를 한 엄지로 누를 때는 엄지를 두 키 사이에 걸칩니다.

**1. ㅏ+ㅓ = ㅡ** — 두 엄지를 함께 누릅니다.

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅡ | `ㅏㅓ` | `c n` | 으 |

**2. ㅣ를 더하면** ㅐ·ㅔ·ㅚ·ㅟ·ㅢ가 됩니다.

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅐ | `ㅏㅣ` | `c m` | 애 |
| ㅔ | `ㅓㅣ` | `n m` | 에 |
| ㅚ | `ㅗㅣ` | `x m` | 외 |
| ㅟ | `ㅜㅣ` | `v m` | 위 |
| ㅢ | `ㅏㅓㅣ` | `c n m` | 의 |

**3. `*`를 더하면** y 소리가 붙습니다(ㅑ·ㅕ·ㅛ·ㅠ). ㅒ는 ㅐ(ㅏ+ㅣ)에 `*`를 더하는 게 아니라 ㅏ+`*`+ㅓ입니다.

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅑ | `ㅏ*` | `c b` | 야 |
| ㅕ | `*ㅓ` | `b n` | 여 |
| ㅛ | `ㅗ*` | `x b` | 요 |
| ㅠ | `ㅜ*` | `v b` | 유 |
| ㅒ | `ㅏ*ㅓ` | `c b n` | 얘 |

**4. ㅗ·ㅜ를 다른 모음과 함께** 누르면 ㅘ·ㅙ·ㅝ·ㅞ가 됩니다.

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅘ | `ㅗㅏ` | `x c` | 와 |
| ㅙ | `ㅗㅏㅣ` | `x c m` | 왜 |
| ㅝ | `ㅜㅓ` | `v n` | 워 |
| ㅞ | `ㅜㅓㅣ` | `v n m` | 웨 |

**5. 예외: ㅖ = ㅗ+ㅓ+ㅣ** — 규칙대로라면 오른손 엄지로 세 키(`b n m`)를 눌러야 해서, 쉽게 누르도록 따로 정했습니다.

| 모음 | 획 | 누를 키 | 결과 |
| --- | --- | --- | --- |
| ㅖ | `ㅗㅓㅣ` | `x n m` | 예 |

## 연습 2: 모음만으로 된 단어

단어가 끝나면 띄어쓰기(`b`)를 칩니다.

아이, 오이, 우유, 여우, 이유, 우애, 여유, 예의, 의외, 아야

<details>
<summary>정답 보기</summary>

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅏ/ㅣ` | `c` → `m` | 아이 |
| `ㅗ/ㅣ` | `x` → `m` | 오이 |
| `ㅜ/ㅜ*` | `v` → `v b` | 우유 |
| `*ㅓ/ㅜ` | `b n` → `v` | 여우 |
| `ㅣ/ㅜ*` | `m` → `v b` | 이유 |
| `ㅜ/ㅏㅣ` | `v` → `c m` | 우애 |
| `*ㅓ/ㅜ*` | `b n` → `v b` | 여유 |
| `ㅗㅓㅣ/ㅏㅓㅣ` | `x n m` → `c n m` | 예의 |
| `ㅏㅓㅣ/ㅗㅣ` | `c n m` → `x m` | 의외 |
| `ㅏ/ㅏ*` | `c` → `c b` | 아야 |
