# 6과. 띄어쓰기·고치기·문장부호·숫자

## 띄어쓰기

음절끼리는 자동으로 붙고, 단어 사이는 `*`(`b`)로 띄웁니다. 조사([7과](07-조사.md)) 뒤에는 자동으로 띄어지므로 `*`를 치지 않아도 됩니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ/ㄴㅏ` | `e c` → `t c` | 가나 |
| `ㄱㅏ/*/ㄴㅏ` | `e c` → `b` → `t c` | 가 나 |

## 되돌리기와 지우기

**되돌리기**(`-ㅂㄴ`, `h j`)는 방금 친 **획**을 통째로 취소합니다. 여러 번 치면 계속 거슬러 올라가며 취소합니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ/ㄴㅏ/-ㅂㄴ` | `e c` → `t c` → `h j` | 가 ("나" 취소) |
| `ㄱㅏ/ㄴㅏ/-ㅂㄴ/-ㅂㄴ` | `e c` → `t c` → `h j` → `h j` | (둘 다 취소) |

글자 하나만 지울 때와 줄을 바꿀 때는 아래 획을 씁니다.

| 하는 일 | 획 | 누를 키 |
| --- | --- | --- |
| 글자 하나 지우기 (백스페이스) | `*ㅂㄴ` | `b h j` |
| 줄 바꾸기 | `-ㅂㄴㅅㅈ` | `h j k l` |

## 띄어쓰기 없애기

조사([7과](07-조사.md))나 "그리고" 같은 약어([9과](09-약어.md))는 뒤를 자동으로 띄웁니다. 그 뒤에 띄우지 않고 붙여 써야 할 때는 아래 두 획을 씁니다. 영어 속기에서 띄어쓰기를 지우는 획(D-LS)을 한글 자음으로 옮긴 것입니다(D→ㄷ, L→ㄹ, S→ㅅ).

| 하는 일 | 획 | 누를 키 |
| --- | --- | --- |
| 다음 말을 앞말에 붙이기 | `ㄷ-ㄹㅅ` | `a i k` |
| 방금 친 말 앞의 띄어쓰기 지우기 | `ㄷ*ㄹㅅ` | `a b i k` |

- `ㄷ-ㄹㅅ`은 붙일 말을 치기 **전에** 칩니다.
- `ㄷ*ㄹㅅ`은 띄어진 것을 보고 **나서** 칩니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㅅㅏ/ㄱㅗㅏ/-ㄴ/ㅗ*` | `d c` → `e x c` → `j` → `x b` | 사과는 요 (조사 뒤라서 띄어짐) |
| `ㅅㅏ/ㄱㅗㅏ/-ㄴ/ㄷ-ㄹㅅ/ㅗ*` | `d c` → `e x c` → `j` → `a i k` → `x b` | 사과는요 |
| `ㅅㅏ/ㄱㅗㅏ/-ㄴ/ㅗ*/ㄷ*ㄹㅅ` | `d c` → `e x c` → `j` → `x b` → `a b i k` | 사과는요 |

`*`로 직접 넣은 띄어쓰기는 이 두 획으로 지워지지 않습니다. 그때는 되돌리기(`-ㅂㄴ`)를 쓰세요.

## 문장부호

문장부호는 숫자 키 `1`과 받침 키를 함께 누릅니다. 앞말에 붙고, 뒤는 띄어집니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ/1-ㅇ` | `e c` → `1 u` | 가. |
| `ㄱㅏ/1-ㄹ` | `e c` → `1 i` | 가, |
| `ㄱㅏ/1-ㄱ` | `e c` → `1 o` | 가? |
| `ㄱㅏ/1-ㄷ` | `e c` → `1 p` | 가! |

`*`(`b`)를 더하면 뒤도 붙습니다. 소수점처럼 띄우지 않아야 할 때 씁니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `ㄱㅏ/1-ㅇ/ㄴㅏ` | `e c` → `1 u` → `t c` | 가. 나 |
| `ㄱㅏ/1*ㅇ/ㄴㅏ` | `e c` → `1 b u` → `t c` | 가.나 |

다른 기호는 [부록](11-한눈에-보기.md#기호)에 있습니다.

## 숫자

- 숫자는 맨 윗줄 숫자 키를 그대로 씁니다.
- 한 획에 숫자 키를 여러 개 누르면 작은 수부터 차례로 나옵니다.
- `*`(`b`)를 더하면 거꾸로 나옵니다.
- 같은 숫자가 두 번 나오거나 순서가 섞인 수는 여러 획으로 나눠 칩니다. 숫자끼리는 자동으로 붙습니다.

| 획 | 누를 키 | 결과 |
| --- | --- | --- |
| `1` | `1` | 1 |
| `1234` | `1 2 3 4` | 1234 |
| `12*` | `1 2 b` | 21 |
| `2/-0/2/4` | `2` → `0` → `2` → `4` | 2024 |

"하나", "다섯째", "km" 같은 숫자 관련 약어는 [9과](09-약어.md#숫자와-단위)에 있습니다.
