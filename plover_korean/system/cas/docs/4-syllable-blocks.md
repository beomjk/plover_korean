# Syllable Blocks

Syllable blocks are the foundation of written Korean, and so of this system too. Apart from the number keys, the layout pictured below has three main sections:

![CAS Layout](https://i.imgur.com/T9Kfc07.png)

- Initial consonants, pressed with the left hand.
- Medial vowels, pressed with the thumbs.
- Final consonants, pressed with the right hand.

To see how this layout can easily write every Korean syllable block, you need to know [how syllable blocks are built](https://en.wikipedia.org/wiki/Hangul#Morpho-syllabic_blocks).

## Initial Consonants

Every basic consonant has its own key and works as you would expect. Aspirated and tensed consonants are written by pressing a combination of basic consonants at the same time.

For an aspirated consonant, combine the basic consonant with `ㅎ`:

- `ㅎㅈ`: ㅊ
- `ㅎㄱ`: ㅋ
- `ㅎㄷ`: ㅌ
- `ㅎㅂ`: ㅍ

For a tensed consonant, combine the basic consonant with `ㅇ`:

- `ㅈㅇ`: ㅉ
- `ㄱㅇ`: ㄲ
- `ㄷㅇ`: ㄸ
- `ㅇㅂ`: ㅃ
- `ㅇㅅ`: ㅆ

A Korean syllable never has more than one initial consonant, so using `ㅎ` and `ㅇ` this way causes no conflicts.

When a syllable block starts with `ㅇ`, leave it out of the stroke; it is implied. This frees the initial `ㅇ` key for other uses, covered later.

An initial consonant pressed on its own outputs a brief, not the letter. To practice building syllable blocks, always combine initial consonants with a vowel, and optionally a final consonant.

## Medial Vowels

Basic vowels have their own keys, and complex vowels are built from their parts. The `*` key works as a modifier that "doubles" a vowel, except for `ㅖ`: following the usual pattern would mean pressing three keys with one thumb, so `ㅖ` uses an easier fingering instead.

A vowel stroke on its own outputs that vowel as a syllable:

- `ㅗ`: 오
- `ㅏ`: 아
- `ㅜ`: 우
- `-ㅓ`: 어
- `-ㅣ`: 이
- `ㅏㅓ`: 으
- `ㅏㅣ`: 애
- `-ㅓㅣ`: 에
- `ㅗ*`: 요
- `ㅏ*`: 야
- `ㅜ*`: 유
- `-*ㅓ`: 여
- `ㅏ*ㅓ`: 얘
- `ㅗㅓㅣ`: 예
- `ㅏㅓㅣ`: 의
- `ㅗㅣ`: 외
- `ㅜㅣ`: 위
- `ㅗㅏ`: 와
- `ㅜㅓ`: 워
- `ㅗㅏㅣ`: 왜
- `ㅜㅓㅣ`: 웨

## Final Consonants

Final consonants are written just like [initial consonants](#initial-consonants), although their keys are in different positions and in a different order.

One key difference is that Korean has these double final consonants, each made of two consonants:

- ㄳ
- ㄵ
- ㄶ
- ㄺ
- ㄻ
- ㄼ
- ㄽ
- ㄾ
- ㄿ
- ㅀ
- ㅄ

As with aspirated and tensed consonants, you press both consonants at the same time. None of them contain `ㅇ`. ㄶ and ㅀ contain `ㅎ`, as do ㄾ and ㄿ through ㅌ (`ㅎㄷ`) and ㅍ (`ㅎㅂ`), but ㄴ and ㄹ have no aspirated forms, so these combinations are never ambiguous.

## Examples

Here are some examples that put these rules together:

- `ㅈㅏ`: 자
- `ㅈㅏㅁ`: 잠
- `ㅗㅅ`: 옷
- `-ㅓㄱ`: 억
- `ㅎㄱㅗㅇ`: 콩
- `ㄷㅇㅏㅇ`: 땅
- `ㅎㅗㅣ/ㅏㅓㅣ`: 회의
- `ㅅㅣ/ㄱㅗㅓㅣ`: 시계

All of the examples above end with an implicit attach operator, `{^}`, as does every syllable block written this way.
