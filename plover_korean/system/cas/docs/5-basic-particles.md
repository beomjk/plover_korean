# Basic Particles

These particles are used on their own, but many of the right-hand ones will also show up as patterns in more complex briefs later on.

- `ㅇㅗㅏ`: {^}와 / {^}과
- `-ㄹ`: {^}을 / {^}를
- `-ㅇㄴ`: {^}은
- `-ㄴ`: {^}는
- `-ㅇ`: {^}의
- `ㅇㅓㅣ`: {^}에
- `ㅇㅣ`: {^}이
- `ㅇㅜㅓ`: {^}워
- `-ㅎ`: {^}히
- `-ㅁ`: {^}며
- `-ㄷ`: {^}도
- `-ㅅ`: {^}서
- `-ㅈ`: {^}지
- `-ㄱ`: {^}고
