# Korean Modern S Documentation

Korean Modern S is based on the stenography system used by Sorizava machines. It is disabled: to try it, uncomment its `plover.system` entry point in `pyproject.toml` and reinstall the plugin. It has not been tested, and there are no plans to work on its dictionary or fix its issues for now; it is kept here for future reference and development.

If you have theory books or other Sorizava resources that could help, please get in touch!
